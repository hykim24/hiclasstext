학교 현장을 이해한 문자 서비스

빠르고 정확한 발송은 기본,
보안과 관리까지 학교 기준에 맞췄습니다.

학교 특화 기능

  • 학교 조직 기반 연락처 관리
  • 간편한 발송 대상자 선택
  • 반별, 학년별 그룹 관리
  • 학교 대표 번호 발송
  • 교직원 권한별 기능 접근 관리
  • 교직원 본인 인증 기반 이용
  • 교직원별 이용 발송 설정

고급 발송 기능

  • 학생별 정보 자동 입력 (메일머지)
  • 다국어 자동 번역 문자
  • 학교 업무 최적화 템플릿
  • 단체 발송 / 예약 발송
  • 대량 발송, 심야 시간 발송 제한 설정 및 관리

투명한 관리 시스템

  • 발송 내역 상세 대시보드
  • 대량 문자 발송 전송 자격 인증
  • 발송 실패건 100% 자동 환급
  • IP·이메일 2차 인증으로 외부 접근 차단
  • 휴대폰번호 마스킹 처리
  • 주소록 다운로드·수정 이력 로그 제공

주요 기능

학교 업무에 최적화된 문자 발송 기능

메일 머지 기능

학생별로 다른 내용을 자동으로 삽입하여 개인화된 문자를 대량 발송할 수 있습니다.

학교 연락처로 발송

학교 대표 번호로 발송하여 신뢰도를 높이고 학부모가 안심하고 받을 수 있습니다.

다문화 번역 발송

다양한 언어로 자동 번역하여 발송할 수 있어 다문화 가정과의 소통이 원활합니다.

발송 내역 자동 저장

모든 발송 내역이 자동으로 저장되어 언제든지 확인하고 재발송할 수 있습니다.

실시간 대시보드

발송 현황과 통계를 한눈에 확인하고 효율적으로 관리할 수 있습니다.

보안 인증

교직원 본인 인증 및 IP·이메일 인증, 대량·심야 발송 제한 등 개인정보 데이터 관리를 위한 보안 시스템을 적용합니다.

상세 기능

하이클래스 문자 서비스가 제공하는 다양한 발송 및 관리 기능을 확인하세요

일부 기능은 순차적으로 업데이트될 예정입니다.

문자 보내기

다양한 방식으로 효율적인 문자 발송

  • 개별, 단체 (전교생, 학년, 학급별) 발송
  • 예약 발송 기능
  • SMS/LMS 지원

특별 기능

더욱 편리하고 스마트한 문자 발송

  • 다국어 자동 번역
  • 메일머지 기능
  • 템플릿 관리
  • 클립보드 활용

주소록 관리

학교 조직 기반의 체계적인 연락처 관리

  • 학급별, 학년별 그룹
  • 엑셀 일괄 등록
  • 검색 및 필터링

발송 내역 관리

모든 발송 기록을 체계적으로 관리

  • 발송 내역 자동 저장
  • 성공/실패 상태 확인
  • 발송 내역 기반 재발송
  • 엑셀 다운로드

권한 관리

담당자별 적절한 권한 설정

  • 교사별 발송 권한 설정
  • 주소록 열람 제한
  • 개인정보 보호 강화
  • 교직원별 이용 발송 설정

신청 & 충전

간편한 신청과 다양한 충전 요금제

  • 간편한 서비스 신청
  • 발신번호 관리
  • 다양한 충전 요금제
  • 잔액 알림 & 자동 충전

실시간 대시보드

발송 현황과 통계를 한눈에 파악

  • 발송 통계 시각화
  • 잔여 포인트 실시간 확인
  • 월별/일별 발송 현황

보안 인증

개인정보 보호를 위한 철저한 보안 체계

  • 본인 인증 및 IP, 이메일 인증
  • 세션 타임아웃 관리
  • 휴대폰번호 마스킹 처리
  • 주소록 다운로드 시 교직원 인증
  • 주소록 수정 이력 로그 제공
